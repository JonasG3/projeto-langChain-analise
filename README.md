# projeto-langChain-analise
Projeto de análise inteligente de dados em CSV: aplicação desenvolvida em Python que permite ao usuário fazer o upload de arquivos CSV e interagir com os dados por meio de linguagem natural. O sistema utiliza agentes de IA para responder perguntas sobre o conjunto de dados, gerar resumos automáticos, produzir estatísticas descritivas e gráficos.
